Every route is scoped by chronicle. Today the only supported chronicle is `interlude`.

Most list endpoints support `limit` and `offset` for pagination. There are no other query filters at the moment. `armor-sets`, `locations`, and `regions` return all records in a single response — `limit` and `offset` are ignored on those.

## Common requests

Five tasks people typically want to do:

**Get an item by ID**
```bash
curl https://l2api.dev/api/interlude/items/8689
```

**List items, ten at a time**
```bash
curl 'https://l2api.dev/api/interlude/items?limit=10&offset=0'
```

**Who drops this item?**
```bash
curl https://l2api.dev/api/interlude/items/8689/dropped-by
```

**Who spoils this item?**
```bash
curl https://l2api.dev/api/interlude/items/8689/spoiled-by
```

**What does this NPC drop, sell, and where does it spawn?**
```bash
curl https://l2api.dev/api/interlude/npcs/29001/drops
curl https://l2api.dev/api/interlude/npcs/29001/shop
curl https://l2api.dev/api/interlude/npcs/29001/spawns
```

**The OpenAPI spec**
```bash
curl https://l2api.dev/api/openapi.json
```

## Items

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/[chronicle]/items` | GET | List items. Supports `limit` and `offset`. |
| `/api/[chronicle]/items/:id` | GET | Get a single item by ID. |
| `/api/[chronicle]/items/:id/dropped-by` | GET | NPCs that drop this item, with rates. |
| `/api/[chronicle]/items/:id/spoiled-by` | GET | NPCs that spoil this item, with rates. |

## NPCs

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/[chronicle]/npcs` | GET | List NPCs. Supports `limit` and `offset`. |
| `/api/[chronicle]/npcs/:id` | GET | Get a single NPC by ID. |
| `/api/[chronicle]/npcs/:id/drops` | GET | Drop table for this NPC. |
| `/api/[chronicle]/npcs/:id/shop` | GET | Items this NPC sells (if any). |
| `/api/[chronicle]/npcs/:id/spawns` | GET | Where this NPC spawns. |
| `/api/[chronicle]/drops/npc/:id` | GET | Alternative enriched drop view for an NPC. |

## Raw endpoints

Raw endpoints return source-faithful records without deduplication or grouping. Useful for auditing, debugging, or comparing against the upstream datapack.

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/[chronicle]/raw/npcs` | GET | All raw NPC records. |
| `/api/[chronicle]/raw/npcs/:id` | GET | A single raw NPC record. |
| `/api/[chronicle]/raw/monsters` | GET | All raw monster records. |
| `/api/[chronicle]/raw/monsters/:id` | GET | A single raw monster record. |
| `/api/[chronicle]/raw/monsters/:id/spawns` | GET | Spawn entries for a raw monster. |
