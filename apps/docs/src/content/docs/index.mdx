A public, read-only API for **Lineage 2 Interlude** game data.

Fetch items, monsters, NPCs, drops, quests, classes, armor sets, locations, hennas, and more. Perfect for wikis, guides, price checkers, loot tables, and data exploration tools.

## Base URL

```
https://l2api.dev/api/interlude
```

All game-data routes are scoped by **chronicle**. Currently, `interlude` is the only supported chronicle.

## Popular requests

**Fetch a boss (Queen Ant):**
```bash
curl https://l2api.dev/api/interlude/npcs/29001
```

**List items with pagination:**
```bash
curl 'https://l2api.dev/api/interlude/items?limit=10&offset=0'
```

**Fetch a quest (Letters of Love):**
```bash
curl https://l2api.dev/api/interlude/quests/1
```

**List an armor set:**
```bash
curl https://l2api.dev/api/interlude/armor-sets/1
```

**Search the OpenAPI spec:**
```bash
curl https://l2api.dev/api/openapi.json
```

## Main resources

| Resource | Description |
|----------|-------------|
| **items** | Weapons, armor, consumables, quest items, spellbooks, recipes |
| **npcs** | Non-player characters: merchants, guards, quest givers |
| **monsters** | Combat mobs: regular enemies, bosses, raid bosses |
| **drops** | Monster drop and spoil rates by item |
| **quests** | Quest catalog, objectives, rewards |
| **classes** | Player classes and skill-learn progression |
| **armor-sets** | Armor set pieces and set bonuses |
| **locations** | Hunting zones and map locations |
| **hennas** | Dye and symbol cosmetic and stat items |
| **regions** | Geographic regions and zone groupings |

## Response format

**Single resource:**
```json
{
  "data": { }
}
```

**List of resources:**
```json
{
  "data": [ ],
  "meta": {
    "total": 9206,
    "limit": 50,
    "offset": 0
  }
}
```

Use the `limit` and `offset` parameters to paginate. See **Response Format** for full details on pagination, caching headers, and error handling.

## Public vs raw data

The API exposes two layers:

- **Public endpoints:** Cleaned, deduplicated, cross-linked data for players and developers
- **Raw endpoints:** One-to-one source records for auditing and data verification

Example: `/api/interlude/items` (public) vs `/api/interlude/raw/items` (raw)

Learn more in **Core Concepts**.

## No authentication required

The API is public. No API keys or credentials needed. CORS is enabled for browser-based requests.
