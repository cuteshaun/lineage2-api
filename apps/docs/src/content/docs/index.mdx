A public, read-only HTTP API for **Lineage 2 Interlude** game data.

## Base URL

```
https://l2api.dev/api/interlude
```

Every route is scoped by **chronicle**. Today the only supported chronicle is `interlude`.

## Main resources

| Resource | URL | What's there |
|----------|-----|--------------|
| **items** | [`/api/interlude/items?limit=10`](https://l2api.dev/api/interlude/items?limit=10) | Weapons, armor, consumables, quest items, spellbooks, recipes |
| **npcs** | [`/api/interlude/npcs?limit=10`](https://l2api.dev/api/interlude/npcs?limit=10) | Non-player characters: merchants, guards, quest givers |
| **monsters** | [`/api/interlude/monsters?limit=10`](https://l2api.dev/api/interlude/monsters?limit=10) | Combat mobs: regular enemies, bosses, raid bosses |
| **quests** | [`/api/interlude/quests`](https://l2api.dev/api/interlude/quests) | Quest catalog, objectives, rewards |
| **classes** | [`/api/interlude/classes`](https://l2api.dev/api/interlude/classes) | Player classes and skill progression |
| **hennas** | [`/api/interlude/hennas`](https://l2api.dev/api/interlude/hennas) | Dye and symbol items |
| **armor-sets** | [`/api/interlude/armor-sets`](https://l2api.dev/api/interlude/armor-sets) | Armor set pieces and set bonuses |
| **locations** | [`/api/interlude/locations`](https://l2api.dev/api/interlude/locations) | Hunting zones and map locations |

`items`, `npcs`, and `monsters` are paginated and searchable (`?q=wolf`, `?limit=10`, see [Query parameters](/endpoints/#query-parameters)). `quests`, `classes`, `hennas`, `armor-sets`, and `locations` are small catalogs returned in full in one response. URLs are relative to the base `https://l2api.dev`.

## Response shape

```json
// single resource
{ "data": { } }

// list resource
{ "data": [ ], "meta": { } }
```

Always read from `data`. See [Endpoints](/endpoints/) for query parameters, pagination and errors, and [Code examples](/examples/) for ready-to-run `fetch` snippets.

## No authentication

No API keys. CORS is enabled, so browser apps can call the API directly.
