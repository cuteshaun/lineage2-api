A public, read-only HTTP API for **Lineage 2 Interlude** game data — items, NPCs, monsters, drops, quests, classes, and more. Useful for wikis, guides, price checkers, loot tables, Discord bots, and exploration tools.

## Base URL

```
https://l2api.dev/api/interlude
```

Every route is scoped by **chronicle**. Today the only supported chronicle is `interlude`.

## Main resources

| Resource | What's there |
|----------|--------------|
| **items** | Weapons, armor, consumables, quest items, spellbooks, recipes |
| **npcs** | Non-player characters: merchants, guards, quest givers |
| **monsters** | Combat mobs: regular enemies, bosses, raid bosses |
| **quests** | Quest catalog, objectives, rewards |
| **classes** | Player classes and skill progression |
| **hennas** | Dye and symbol items |
| **armor-sets** | Armor set pieces and set bonuses |
| **locations** | Hunting zones and map locations |
| **regions** | Geographic regions and zone groupings |

See [Endpoints](/endpoints/) for the full route list.

## Examples

```bash
# An item (Bloody Orchid, a Grade A dagger)
curl https://l2api.dev/api/interlude/items/235

# A monster (Queen Ant)
curl https://l2api.dev/api/interlude/monsters/29001

# A quest (Letters of Love)
curl https://l2api.dev/api/interlude/quests/1
```

## Response shape

```json
// single resource
{ "data": { } }

// list resource
{ "data": [ ], "meta": { } }
```

Always read from `data`. List endpoints accept `limit` and `offset` (default limit `50`, max `200`). See [Response Format](/response-format/) for the full envelope, errors, and caching.

## No authentication

The API is public — no API keys, no credentials. It's read-only, and CORS is enabled, so you can call it directly from a browser.
