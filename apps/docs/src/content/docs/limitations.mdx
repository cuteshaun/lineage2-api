This is an unofficial, community project — **not affiliated with or endorsed by NCSoft**. Lineage and Lineage 2 are trademarks of their respective owners.

## Covered

- **Interlude** chronicle only
- Read-only, public game data
- items, NPCs, monsters, drops & spoil, quests, classes, hennas, locations, regions, armor sets
- Generated JSON served over HTTP
- Cleaned, cross-linked public DTOs (see [Response Format](/response-format/#public-vs-raw))
- An [OpenAPI spec](/openapi/)

## Not covered

- Other chronicles, for now
- Auth, accounts, comments, ratings, or moderation
- Runtime game-server behavior
- Full formula or damage simulation
- AI scripts
- Geodata or exact polygon location resolution — coordinates are nearest-anchor hints, not boundaries
- Official NCSoft affiliation

Records come from the aCis Interlude datapack. Differences from other references (L2Hub, PTS, L2Wiki) are source differences, not API bugs. Issues and PRs are welcome — see [How to Contribute](/local-development/).
