## Fetch an item by ID

Use when you know the item's numeric ID and want its full record.

**Endpoint:** `GET /api/[chronicle]/items/:id`

```bash
curl https://l2api.dev/api/interlude/items/235
```

```json
{
  "data": {
    "id": 235,
    "name": "Bloody Orchid",
    "type": "weapon",
    "grade": "a",
    "category": { "bodypart": "One-handed", "weaponType": "DAGGER" },
    "stats": { "pAtk": 186, "mAtk": 107, "rCrit": 12 }
  }
}
```

## Find who drops an item

Given an item, list the NPCs that drop it, with rates.

**Endpoint:** `GET /api/[chronicle]/items/:id/dropped-by`

```bash
curl https://l2api.dev/api/interlude/items/235/dropped-by
```

```json
{
  "data": [
    {
      "npc": { "id": 29019, "name": "Antharas", "type": "GrandBoss", "level": 79 },
      "qty": "1–2",
      "chance": 25,
      "chanceDisplay": "25%",
      "rollCount": 4
    }
  ],
  "meta": { "total": 32, "limit": 50, "offset": 0 }
}
```

## Get an NPC's drop table

Given an NPC, list every item they can drop and the rate.

**Endpoint:** `GET /api/[chronicle]/npcs/:id/drops`

```bash
curl https://l2api.dev/api/interlude/npcs/29001/drops
```

```json
{
  "data": {
    "npcId": 29001,
    "npcName": "Queen Ant",
    "drops": [
      {
        "itemId": 57,
        "itemName": "Adena",
        "qty": "140000–170000",
        "chance": 100,
        "chanceDisplay": "100%",
        "type": "adena",
        "rollCount": 7
      }
    ]
  }
}
```

## See what an NPC sells

For merchant NPCs, list the items in their buy list with prices.

**Endpoint:** `GET /api/[chronicle]/npcs/:id/shop`

```bash
curl https://l2api.dev/api/interlude/npcs/30001/shop
```

```json
{
  "data": {
    "npc": { "id": 30001, "name": "Lector" },
    "buyList": [
      {
        "itemId": 1,
        "name": "Short Sword",
        "iconFile": "weapon_small_sword_i00.png",
        "price": 883,
        "buyListId": 1
      }
    ]
  }
}
```

NPCs without a shop return `404`. Use the NPC's `type` (e.g. `Merchant`) on `/npcs/:id` to know which ones to query.

## Find where an NPC spawns

Given an NPC, list every spawn point with coordinates, respawn timing, and region.

**Endpoint:** `GET /api/[chronicle]/npcs/:id/spawns`

```bash
curl https://l2api.dev/api/interlude/npcs/29001/spawns
```

```json
{
  "data": [
    {
      "npcId": 29001,
      "x": -21610,
      "y": 181594,
      "z": -5734,
      "respawnDelay": 0,
      "region": { "id": 5, "name": "Town of Gludio" },
      "location": { "id": 33, "name": "Wasteland", "minLevel": 25 }
    }
  ]
}
```

Location data is a nearest-anchor hint, not a polygon — see [Scope](/limitations/).

## Fetch a quest by ID

Get a quest's full detail, including involved NPCs and required level.

**Endpoint:** `GET /api/[chronicle]/quests/:id`

```bash
curl https://l2api.dev/api/interlude/quests/1
```

```json
{
  "data": {
    "id": 1,
    "name": "Letters of Love",
    "levelMin": 2,
    "repeatable": false,
    "startNpcs": [{ "id": 30048, "name": "Darin" }],
    "involvedNpcs": [
      { "id": 30006, "name": "Roxxy" },
      { "id": 30033, "name": "Baulro" }
    ]
  }
}
```

## List items with pagination

Walk the items catalog page by page using `limit` and `offset`.

**Endpoint:** `GET /api/[chronicle]/items?limit=N&offset=M`

```bash
curl 'https://l2api.dev/api/interlude/items?limit=2&offset=0'
```

```json
{
  "data": [
    { "id": 1, "name": "Short Sword", "type": "weapon", "grade": "none", "price": 768 },
    { "id": 2, "name": "Long Sword", "type": "weapon", "grade": "none", "price": 136000 }
  ],
  "meta": { "total": 8771, "limit": 2, "offset": 0 }
}
```

Use `meta.total` to compute the number of pages: `Math.ceil(total / limit)`. See [Response Format](/response-format/#pagination).

**Next:** Browse with a different resource — `npcs`, `monsters`, `quests`, `classes`, `hennas` all paginate the same way.

## Explore armor sets and bonuses

Armor sets are returned in one response — each entry includes its pieces and the set bonus skill with concrete stat effects.

**Endpoint:** `GET /api/[chronicle]/armor-sets`

```bash
curl https://l2api.dev/api/interlude/armor-sets
```

```json
{
  "data": [
    {
      "id": 1,
      "name": "Wooden Set",
      "pieces": {
        "chest": { "itemId": 23, "name": "Wooden Breastplate" },
        "legs":  { "itemId": 2386, "name": "Wooden Gaiters" },
        "head":  { "itemId": 43, "name": "Wooden Helmet" }
      },
      "bonusSkill": {
        "name": "Wooden Set",
        "description": "Increases P. Def. and Max HP.",
        "effects": [{ "stat": "pDef", "op": "mul", "value": 1.02 }]
      }
    }
  ]
}
```

No pagination — `limit` and `offset` are ignored. There is no `/armor-sets/:id` route; fetch the list and filter client-side by `id` or `name`.
